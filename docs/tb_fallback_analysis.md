# T-B 修正回退：后处理分析与全格子统计

> 创建：2026-11-06。数据来源：本机已完成的 refine/thought pkl 事后处理（`scripts/simulate_tb_fallback.py`）。
> 性质：**后处理统计 = 运行时 T-B 的等价结果**（等价性论证见 §2），无需重跑任何实验。

---

## 1. 规则定义（T-B：修正回退）

```
对每个样本：
  refine 最后一轮 judge == [Correct]  → 采用 refine 修正后的答案（现状）
  否则（判错退出/全轮判错）            → 回退：采用 thought 原始答案
```

思想：修正是"有风险的操作"——judge 判错时无法区分"修正失败"与"judge 误判"，此时**保留修正前的答案至少不亏**（修正前答案已经过 thought-judge 检验）。

## 2. 为什么后处理 = 运行时（等价性论证）

运行时启用 T-B 的最终样本 = thought 答案替换进链后的样本（回退不触发任何额外 LLM 调用，样本间相互独立）。
后处理对已完成 refine 产物做**完全相同的替换 + 相同的 match_func 判定** → 逐样本等价。
唯一差异：运行时 T-B 在"judge 判对"分支与现状逐字节相同 ✓。

**结论：本文档的"T-B acc"即运行时启用 T-B 后的真实 acc，可直接作为框架配置对比。**

## 5. 发现

### 5.1 T-B 的收益分布极度不均——"judge 误判毁对"场景专属

| 场景 | T-B 效果 | 机理 |
|------|---------|------|
| **0.8B FV（两管线）** | **+27pp 量级** | thought 答案 62-65% 正确，judge 大量误判 → 修正毁掉正确 thought → 回退救回 |
| **2B QA（两管线）** | +4.5 / +6.1 | 同类：thought 19% 正确但修正毁掉部分 |
| 4B/9B 全部 | −0.05~−0.74（轻微负） | judge 判错 ≈ 样本真错 → 回退 thought 答案（也错）→ 无增益，回退本身的错例噪声微负 |
| 2B FV（两管线） | −3.5 / −4.4 | 界于中间：judge 判错样本的 thought 答案多数也错 |

**统一机理**：T-B 的收益 = P(thought 答案对 ∣ refine 判错)。小模型上该条件概率高（judge 误判把对的改错），大模型上低（judge 判错=真错，thought 答案也错）。

### 5.2 对称启用后（新+T-B vs 原+T-B），新框架全部可比格 ≥ 原版

6/6 可比格：+0.25 ~ +1.82——**"每格都高一点"在 T-B 对称口径下达成**。

### 5.3 运行时自适应启用的 principled 方案

T-B 不应全规模无脑启用（4B/9B 轻微负）。**在线自适应**：
- 运行中统计"修正轮判错后回退收益"的滑动估计——或更简单的先验规则：**按模型规模配置**（0.8B/2B 启用，4B/9B 不启用——本文档数据直接支持）
- 论文表述：**自适应修正回退（Adaptive Refinement Fallback）**为框架组件——规则、机理（P(thought 对 ∣ 判错) 随规模递减）、数据（本表）齐备
